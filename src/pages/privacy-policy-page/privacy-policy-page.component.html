GitHub-API

Auf der Dependencies-Seite wird die aktuelle Versionsnummer einzelner Projekte direkt im Browser über die öffentliche API von GitHub (api.github.com) abgefragt. Dabei wird die IP-Adresse an GitHub übertragen. Das Ergebnis wird lediglich zur Vermeidung wiederholter Anfragen für die Dauer der Sitzung im sessionStorage des Browsers zwischengespeichert und beim Schließen des Tabs automatisch gelöscht.
