General

This website does not use cookies, tracking, or analytics tools. There is no registration and no user accounts. Personal data is processed only to the extent necessary for the technical operation of the site.

Server Log Files

When you access this website, the server automatically collects information transmitted by your browser (including IP address, date and time, page requested, referrer, browser type). This data is used solely for the technical provision and security of the website (Art. 6(1)(f) GDPR, legitimate interest) and is not combined with other data sources.

Google Fonts

This website embeds fonts from Google Fonts, which are loaded directly from Google LLC's (USA) servers when the page is accessed. In doing so, your IP address is transmitted to Google. More information: Google's Privacy Policy.

Icon Library (jsDelivr CDN)

Technology icons are displayed using the "devicon" library, which is loaded via the jsDelivr CDN. In doing so, your IP address is transmitted to the CDN operator. More information: jsDelivr's Privacy Policy.

The service icons are not affected by this. They are served directly from this website, so no request to a third party is made for them.

GitHub API

On the Dependencies page, the current version number of individual projects is queried directly from the browser via GitHub's public API (api.github.com). In doing so, your IP address is transmitted to GitHub. The result is only cached in the browser's sessionStorage for the duration of the session to avoid repeated requests, and is automatically deleted when the tab is closed.
